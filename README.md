# Миры — ролевая переписка с ИИ

Мобильное приложение для интерактивных историй: каталог персонажей, приватные диалоги, редактор своих героев и генерация изображений. Это самостоятельный проект с оригинальным интерфейсом, а не копия Character.AI или Emochi.

## Возможности

- Android-приложение на Capacitor и устанавливаемая PWA.
- Русский адаптивный интерфейс для телефона и компьютера.
- Каталог персонажей с поиском, жанрами, избранным и сохранёнными чатами.
- Создание персонажей: описание, характер, сеттинг, стиль и приветствие.
- Ролевые ответы и генерация изображений через совместимые с OpenAI API-провайдеры.
- В Android-приложении запросы идут напрямую к выбранному провайдеру; сервер для переписки не требуется.
- Чаты и персонажи сохраняются на устройстве. В веб-версии ключ API хранится на сервере; в APK — в локальных данных приложения.

## Запуск веб-версии

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, напечатанный сервером (обычно `http://localhost:5173`). Перейди в **Настройки**, укажи Base URL, API-ключ и названия моделей.

В веб-версии можно задать AI-настройки в `.env` (скопируй `.env.example` в `.env`) или в интерфейсе. Ключ сохраняется в `data/settings.json` без шифрования, с правами файла `600`.

## Android APK

Android-проект находится в `android/`. Для сборки вручную нужны JDK 21, Android SDK API 36 и Android Build Tools 36:

```bash
npm ci
npm run android:sync
cd android
./gradlew assembleDebug
```

Готовый debug-signed APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. В Windows используй `gradlew.bat assembleDebug`.

Также GitHub Actions собирает установщик при обновлениях ветки `arena/b846dd14-chatairoleplay`. Скачай `Miry-Android-debug.apk` из артефакта **miry-android-installer** соответствующего запуска workflow. Это debug-сборка, не публикация в Play Store; при первой установке Android может попросить разрешить установку приложений из этого источника.

### PWA на Android

В Chrome открой веб-версию по HTTPS и выбери меню → **«Установить приложение»** или **«Добавить на главный экран»**. Для AI-функций сервер веб-версии тоже должен быть доступен телефону.

## Провайдеры моделей

Пример Base URL:

- OpenAI: `https://api.openai.com/v1`
- OpenRouter: `https://openrouter.ai/api/v1`
- Другой сервис, если он поддерживает OpenAI-совместимые `/chat/completions` и `/images/generations`.

Совместимость графической модели, стоимость, доступ и допустимое использование зависят от провайдера. Приложение не обходит правила выбранного API и не обещает работу «без ограничений».

## Безопасность

Это однопользовательский прототип. В веб-версии нет учётных записей, серверные настройки не зашифрованы. В Android APK ключ хранится в локальном хранилище приложения без шифрования. Не передавай APK с уже сохранённым ключом и не выставляй веб-сервер публично без аутентификации, HTTPS и защиты от злоупотреблений.
